## Rozwiązanie

### Narzędzia (10 min)
Narzędzia potrzebne do rozwiązania zadania:
- Konto [GitHub](https://github.com/)
- Zainstalowany [git](https://git-scm.com/install/)
- Zainstalowany [uv](https://docs.astral.sh/uv/getting-started/installation/)
- Edytor kodu np. [VSCode](https://code.visualstudio.com/download?_exp_download=fb315fc982)

### Ustawianie projektu lokalnie (7 min)
Aby rozwiązać zadanie, należy zrobić [fork](https://docs.github.com/en/pull-requests/how-tos/work-with-forks/fork-a-repo#forking-a-repository) repozytorium i rozwiązać je na swoim koncie.
Przy ustawieniach domyślnych powstanie repozytorium: /<twój nick>/Rekrutacja-AI-Med-2026-2027
Na komputerze wejdź do folderu, w którym chcesz mieć projekt, i wykonaj:
```shell
git clone https://github.com/<twój nick>/Rekrutacja-AI-Med-2026-2027.git
```
```shell
cd Rekrutacja-AI-Med-2026-2027
```
Zainstaluj biblioteki:
```shell
uv sync
```
Jeżeli wszystko wykonało się poprawnie, masz gotowe środowisko do pracy!
Możesz otworzyć cały projekt w edytorze kodu.
Przejdź do instrukcji poszczególnych zadań. Nie bój się wykorzystywać wiedzy dostępnej w internecie 😉
Nauka mile widziana — liczy się zrozumienie, a nie wynik. </br>
Powodzenia!

### Publikowanie wyników (2 min)

Zapisz wyniki w repozytorium lokalnym, aby śledzić zmiany.

Dodaj nowe pliki:
```shell
git add .
```
Zapisz postępy lokalnie.
```shell
git commit -m "<Krótki opis zmiany>"
```
Wyślij zmiany do swojego zdalnego repozytorium:
```shell
git push
```
Link do Twojego repozytorium należy umieścić w formularzu rekrutacyjnym jeżeli jeszcze tego nie wykonałeś.
